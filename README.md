## App Functions
### Income
- Display Account Balance
- Calculate Income for the Month
- Display Income for the Year
- Input Entry Form for Income
- List of Every Income Entry
- Ability to Add/Edit/Delete Each Entry

### Expenses
- Display Expenses for the Month
- Input Entry Form for Expenses
- List of Every Expense Entry
- Ability to Add/Edit/Delete Each Entry

### Planning
- Display Account Balance
- Display Money Added for the Month
- Display How Much Till Goal
- Ability to Create/Change Savings Plan
- Convert Set USD to Another Currency
- Calculate Purchase in Another Currency

### Financial Summary
- Display Account Balance
- Display Income for the Month
- Display Expenses for the Month
- Display Income for the Year
- Display Expenses for the Year
- Display Estimated Income for the Month
- Display Estimated Expenses for the Month
- Display Estimated Monthly Leftover (savings)
- Display a Pie Chart for the Breakdown
- Display Mascot for Theme
